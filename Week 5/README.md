# Week 5 – Inclusive Reading Assistant

This folder contains the Week 5 project deliverables, including:

- **Backend:** Source code and required dependencies for the Inclusive Reading Assistant.
- **Screenshots:** Evidence of backend execution and successful testing of the Simplify, Summarize, and Explain functionalities using Swagger UI.
- **Documentation:** The Week 5 project report in PDF and editable DOCX formats.

The backend provides three AI-powered text assistance functionalities: Simplify, Summarize, and Explain.
